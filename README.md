# MEO Engine — Multi-Engine Optimization

Prototype tooling for **GEO (Generative Engine Optimization)** + **AEO (Answer Engine Optimization)** for product pages.

## Run locally

Open `index.html` directly, or:

```bash
npx serve .
```

## Deploy (Vercel)

Import this repo in Vercel — static site, no build step needed.

## What it does (prototype)

- Paste a product page URL or product description
- Runs a mock GEO/AEO audit (structure, schema, FAQ coverage, citation-readiness)
- Shows a score + fix list as a demo of the real engine
